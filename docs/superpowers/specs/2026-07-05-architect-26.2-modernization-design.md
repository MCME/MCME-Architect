# MCME-Architect — Paper 26.2 Modernization Design

- **Status:** Approved design (pre-implementation)
- **Date:** 2026-07-05
- **Branch:** `architect-rework-2026`
- **Baseline:** v2.10.6 (`master` @ `8049b16`); Phase 0 hotfixes already committed on this branch.
- **Related docs:** [`audit.md`](../../../audit.md) (full findings), [`AUDIT-REMEDIATION-PLAN.md`](../../../AUDIT-REMEDIATION-PLAN.md) (phased plan).

## 1. Goal & context

Modernize MCME-Architect to run on **Paper 26.2** for a **coordinated release** alongside the new Perks plugin and the new TheGaffer. This is not a bare version bump: alongside the migration we fold in the audit's **High/Medium security & correctness fixes** ("migrate + stabilize"). TheGaffer already made the same 26.x jump, so its migration serves as a template.

**In scope:** 26.2 migration (including any API changes 26.x forces), removal of ProtocolLib in favour of Paper-native APIs, removal of the PluginUtils dependency (spike-gated), the audit's High/Medium fixes, and a MockBukkit test harness.

**Out of scope (deferred):** Conversation→Dialog migration; cosmetic/dead-code cleanup and logging normalization (audit Low/hygiene); deep new-API adoption (Display Entities, broad Dialog UIs); Low-severity audit items.

## 4. Approach — three waves

Approach 1 gets a **runnable 26.2 build early** (for integration against Perks/TheGaffer) and stands the **test harness up before** the risky security fixes. Cost: a few files are touched twice.

Order: **Foundation** (build + harness) → **Wave A** (compile) → **Wave B** (runnable) → **Wave C** (stabilize slices). Wave A proceeds against whatever PluginUtils/MCME-Connect builds exist; every point where Architect needs a not-yet-ready 26.2 lib API becomes an explicit tracked blocker.

## 5. Wave A — compile on 26.2

Goal: `mvn compile` green against `26.1.2-stable`, and the test harness in place.

### 5.1 Foundation
- Repoint `paper-api` to `26.1.2-stable`; confirm JDK target (21 today; 26.x may require newer — JDK 25 available locally).
- Stand up MockBukkit + JUnit 5, `src/test` tree, version matched to the 26.1.2 registry.

### 5.2 Forced API migration
- **Material/enum renames** — sweep for renamed/removed constants (e.g. `GRASS`→`SHORT_GRASS`) across special-block and blockData code.
- **Removed/deprecated APIs** catalogued in the audit — `ItemStack` durability + `(mat,1,short)` constructor, legacy sign `setLine`, and any 1.20→26.x removals → modern equivalents (data components / `Damageable` / Side API).
- **protocolVersions.yml refresh** — add 768/769, fix the 1.21.2 mapping (audit Medium); required for RP client detection on 26.x.

### 5.3 ProtocolLib removal → Paper-native
- **Sign editor** (`SpecialBlockSign`, `OPEN_SIGN_EDITOR`) → `Player#openSign` (clean swap).
- **View distance** (`ViewDistanceListener`, LOGIN/UNLOAD_CHUNK/VIEW_DISTANCE packet manipulation) → Paper Player API. **Verify-early:** the current code does chunk-unload packet tricks that may lack a 1:1 native equivalent; acceptable outcomes are a small behaviour change or a documented stopgap.

### 5.4 Verify-early items (Wave A gates)
1. **Conversation API availability** — if 26.x removed Bukkit Conversations, "keep Conversations" is impossible; **stop and escalate** (do not silently do the deferred Dialog migration). Affects the custom-inventory editor prompts, `RegionEditConversation`, and `confirmation.*`.
2. **View-distance native equivalent** (§5.3).
3. **JDK target + `api-version`** for 26.x.
4. **WorldEdit 26.2** version availability.
5. **PluginUtils-removal spike** (§6).
6. **MockBukkit registry match**.

## 6. PluginUtils removal (spike-gated workstream)

Removing PluginUtils cuts one of the two "migrating in parallel" blockers and the shared-lib coupling. Usage surface: ~65 import sites, overwhelmingly trivial helpers.

**Spike (Wave A gate) — confirm two unknowns:**
- `/architect checknbt` (op-only) calls `AccessInventory.getItemNBT` — the only live NMS use. Confirm it maps to native 26.x **data-component API** (or that the debug command can be dropped). If it cannot go native, removal would force NMS into Architect and break the Maven-only goal → fall back to "defer" and keep PluginUtils this release.
- `plotStoring.IStoragePlot` (copy/paste) vendors cleanly.

**If green — vendor + swap:**
- Vendor the used components into an internal `com.mcmiddleearth.architect.util` package: `NumericUtil`, `FileUtil`, `message.*` (FancyMessage/MessageType/MessageUtil), `EventUtil`, `WEUtil`, `LegacyMaterialUtil`, `developer.DevUtil/Debugable`, `plotStoring.*`, `confirmation.*`, `BlockUtil`/`VoxelUtil`/`ReflectionUtil` (drop the ones only referenced by dead classes).
- Native-replace or drop `/checknbt`; delete the `nms.*` imports (mostly already dead/commented).
- Swap ~65 imports; remove `PluginUtils` from `pom.xml` and `plugin.yml depend`.

This workstream is a **cut candidate** if the timeline slips (fall back to consuming PluginUtils' 26.2 build).

## 7. Wave B — runnable on the 26.2 dev server

- Loads cleanly (`api-version`, softdepends).
- Fix runtime issues the compiler can't catch: registry/enum mismatches, MockBukkit-vs-live differences, Dialog/Conversation runtime behaviour.
- **Dev-server smoke tests** for the things MockBukkit can't reach: RP switching, special-block place/break, editors, copy/paste, and the ProtocolLib-free **view distance**.
- Exit criterion: a 26.2 build stable enough to integrate against Perks and the new TheGaffer.

## 8. Wave C — stabilize in slices

Each slice = fix **+** MockBukkit tests (TDD-able now the harness exists). Phase 0 (armor-freeze, `/inv delete` auth, dependency guards, `/weselect`+`/sign` guards) is effectively the first slice, already committed.

1. **Path-safety helper** — one "resolve-and-verify-under-base-dir" utility applied to `/chead`, `/vv`, `/banner`, `/armor`, `/get head`.
2. **Load-guard** — "never save a config that failed to load"; skip bad files at enable. Targets: `CustomHeadData.fromFile`, `SpecialSavedInventoryData`, `SpecialBlockInventoryData`, `GetData`, `WorldConfig`, `ZipUtil` (destructive empty-download).
3. **Thread-safety & memory** — `/inv download` reload hop to main thread; `/chead submit` Mojang HTTP off the main thread; concurrent + quit-cleaned per-player maps; `refreshSHA` stream leak + async config write.
4. **Data-layer & placement correctness** — `RpDatabaseConnector` `client` column + `ResultSet`/`InputStream`/executor leaks; item-block NPEs and empty-`contentDamage` crash; cross-owner saved-inventory filename collision; item-frame duplication.
5. **Performance (lower priority, cut candidates)** — reduce per-`BlockBreakEvent` config-tree/blockList scans; cache the TheGaffer reflective `Method` (preserving the load-bearing `hasBuildPermission(Player, Location)` signature); `BlockPhysicsEvent` eager-allocation.

## 9. Testing strategy

- MockBukkit matched to the `26.1.2` paper-api registry; JUnit 5; new `src/test` tree.
- **Focused** coverage: the Wave C security/correctness fixes and migration-critical logic (special-block place/break, RP resolution, the vendored `NumericUtil`/`FileUtil`/`message` helpers). Not broad coverage.
- MockBukkit-unreachable paths (native view distance, real threading, Conversations/Dialog) → Wave B dev-server smoke tests.

## 10. Sequencing & parallel-lib blockers

- Foundation → A → B → C. Wave C slices can run near-parallel once B is green.
- MCME-Connect remains a parallel dependency; PluginUtils is removed (§6), eliminating that blocker.
- Any Architect change that needs a not-yet-shipped 26.2 lib API is logged as an explicit blocker rather than a silent stall.

## 11. Risks & open questions

| Risk | Handling |
|---|---|
| Conversations removed in 26.x | Verify first (§5.4.1); stop & escalate — do **not** auto-migrate to Dialog |
| View-distance has no native 1:1 | Verify (§5.3); accept small behaviour change or documented stopgap |
| `/checknbt` NMS not native-replaceable | Spike gate (§6); fall back to deferring PluginUtils removal |
| WorldEdit / ViaVersion 26.2 gaps | Verify versions in Wave A |
| MockBukkit registry mismatch | Match version to paper-api 26.1.2 |
| Timeline pressure | PluginUtils removal and the Wave C performance slice are explicit cut candidates |

## 12. Success criteria

1. `mvn` build green against `26.1.2-stable`; loads and core features work on the 26.2 dev server.
2. ProtocolLib gone; view-distance and sign-editor features work via native APIs (or documented behaviour change).
3. PluginUtils dependency removed (or explicitly deferred with a recorded reason if the spike fails).
4. Audit High/Medium fixes landed with passing MockBukkit tests.
5. Conversations either still functional as-is, or the removal was escalated and decided.
6. A build integrable with Perks and the new TheGaffer for the coordinated release.
